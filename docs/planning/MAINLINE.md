## 当前工作

**M1-01 独立工程工作面已交付并验证。** 包括固定工具链、Electron/React/TypeScript 工程入口、构建来源、四组合原生打包启动和指定服务器构建。[工程证据](../operations/m1-engineering-2026-11-03.json) · [原生 CI](../operations/m1-desktop-ci-2026-11-03.json)

M0 保持 4/8，M1 保持 0/8。M1-01 整项仍为 IN_PROGRESS：Intel Mac、Windows11 和 Ubuntu 桌面实际安装仍待验，正式签名归 M8。工程骨架并行例外已记录在 ROADMAP/BACKLOG，M1 整体验收的 M0 依赖不变。

本轮主线复核将约500MB原生归档的重复下载移出工程收尾，改为读取约182KB的实际原生任务日志、源码/锁身份、原生启动结果和封存元数据。归档 SHA 在各 CI job 内计算并核对，外部摘要明确不声称独立重读完整二进制；安装与发行验证保留到对应阶段。原失败和下载中断材料均保留。

**M0-02 的 Interface 收口已交付**。原生能力与宿主状态证据已[对账](../../research/m0-contract-admission.md)。本轮修正状态事件归属、提交回执查询、断线快照、Runner 握手、部署能力修订和未知执行迁移。M0-02 保持 IMPLEMENTED，正式准入冻结依赖 M0-05。

**M0-05 / AC-12 Guest TLS 入口已实现并通过回环验证**。入口按请求向可信授权方取决定，在上游拨号前复核，撤销时取消待派发请求或关闭活动响应。E80 验证了真实双 TLS 链路，授权方和上游均为受控测试实现。完整路径仍需将 E30 的隔离 NIC 和 E76 的宿主资源身份接入实际授权。文件、配额及 AC-30 未决项仍按原表执行。

**M0-07 资源核对子项已验证**。确认指定服务器当前资源、本机 macOS arm64 和四组合构建产物可用，列明安装设备、签名授权、独立备份位置的解除条件。[E79](../operations/m007-resource-readiness-2026-11-06.json) 仅为资源证据，M0-07 仍为 IN_PROGRESS。

**M1-01 macOS arm64 内部安装已验证**。复用原生包，在用户 Applications 目录完成安装、严格本机签名检查及已安装可执行文件的启动冒烟。重复安装拒绝覆盖。签名、失败回收和验证范围见[实际报告](../operations/m101-macos-arm64-install-2026-11-06.json)；本机 ad-hoc 签名是内测流程，正式发行按 M8 验收。

**2026-11-12 依赖复核。** 最近的 macOS 内部安装与 Guest TLS 入口都有原任务归属。排程却把 M0-05 的运行隔离要求同时用于阻止控制面和桌面连接开发，导致客户端停留在本地工程入口。M1-06 的身份发现与 M1-07 的 HTTPS 环境探测只需要现有契约及 TLS，可独立开发。M0-05 继续按真实 VM、授权和隔离条件验收。

**M1-06 的 HTTPS 身份发现子项已验证。** 控制面提供 `GET /v1/auth/discovery`，客户端调用复用 canonical Schema，并在本机与指定服务器验证 HTTPS。指定服务器实际启动、响应和回收均有记录。M1-06 保持 IN_PROGRESS，认证握手、持久命令与事件仍按原任务交付。[验收记录](../operations/m106-https-discovery-2026-11-12.json)

**M1-07 的环境探测子项已验证。** 安装版可输入平台 HTTPS 地址，经受限 IPC 调用共享发现客户端。macOS arm64 安装版对实际控制面验证了读取身份配置、证书拒绝与用户操作要求。[验证报告](../operations/m107-desktop-probe-2026-11-12.json)

**M1-07 的 HTTP 发现子项已验证。** 桌面支持 HTTP 与 HTTPS 地址。控制面可显式启用 HTTP 提供公开发现，默认 HTTPS。macOS arm64 安装版对实际监听验证了两种协议，指定服务器同源回归通过。[验证报告](../operations/m107-http-probe-2026-11-12.json)

**M1-07 局域网连通性已验证。** 在指定服务器启用常驻发现服务，并按授权仅放行局域网。Mac 实测 TCP 连通，安装版在真实地址收到身份待配置响应。HTTP 连接探测和身份配置分别显示，M1-07 保持 IN_PROGRESS。[验证报告](../operations/m107-lan-discovery-2026-11-12.json)

**下一原任务为 M1-03 的系统浏览器登录。** 在已有身份发现上接入真实 OIDC，先确认公开 client 注册、回调和可用测试身份，再验证 PKCE、回调状态与系统凭据存储。M1-07 的组织项目导航及多环境凭据隔离随身份功能验证。M0-05 的实际执行授权与隔离 NIC 仍是 M2 真实闭环的前置。

## 每轮主线检查

开工、子任务完成及范围变化时，用 AGENTS 的五条规则核对：原任务、交付、退出条件、当前阻塞、最小验证、下一项。发现偏离立即收敛本轮范围；必要变更在这里和受影响原任务中记录，保留原生产验收要求。

进度格式：`原任务 ID / 实际交付 / 验收结果 / 父任务状态 / 下一项`。原始基础设施证据继续保存，报告优先说明它推进了哪项产品能力或原任务条件。
