## 当前工作

**M1-01 独立工程工作面已交付并验证**：固定工具链/workspace、Electron/React/TypeScript 工程入口、只读桌面 Interface、构建来源、四组合原生打包启动和指定服务器构建。登录、环境连接、Harness 会话尚未实现；[工程证据](../operations/m1-engineering-2026-11-03.json)与[原生CI](../operations/m1-desktop-ci-2026-11-03.json)保持范围区分。

M0 保持 4/8，M1 保持 0/8。M1-01 整项仍为 IN_PROGRESS：Windows Server 构建不能代替 Windows11 安装，目标系统实际安装及正式签名仍按原阶段验收。工程骨架并行例外已记录在 ROADMAP/BACKLOG，M1 整体验收的 M0 依赖不变。

本轮主线复核将约500MB原生归档的重复下载移出工程收尾，改为读取约182KB的实际原生任务日志、源码/锁身份、原生启动结果和封存元数据。归档 SHA 在各 CI job 内计算并核对，外部摘要明确不声称独立重读完整二进制；安装与发行验证保留到对应阶段。原失败和下载中断材料均保留。

**M0-02 的 Interface 收口已交付**。原生能力与宿主状态证据已[对账](../../research/m0-contract-admission.md)。本轮修正状态事件归属、提交回执查询、断线快照、Runner 握手、部署能力修订和未知执行迁移。M0-02 保持 IMPLEMENTED，正式准入冻结依赖 M0-05。

**M0-05 / AC-12 Guest 选择性出网前置已核对**。E30 的固定 TLS 回显入口没有转发和执行授权；E52 的上游传输仅供可信宿主调用；E76 的固定 VM 模板拒绝 NIC，宿主控制凭据与 Guest 授权分离。当前没有贯通的 Guest 路径，继续重跑会重复原证据。解除条件是同一隔离 NIC、限域 TLS 入口、可信当前执行授权与受限上游可共同运行。届时用合成上游验证获准请求通过、错误或撤销授权零上游命中、管理网/横向访问拒绝及精确回收。文件、配额及 AC-30 未决项仍按原表执行。

**M0-07 资源核对子项已验证**。确认指定服务器当前资源、本机 macOS arm64 和四组合构建产物可用，列明安装设备、签名授权、独立备份位置的解除条件。[E79](../operations/m007-resource-readiness-2026-11-06.json) 仅为资源证据，M0-07 仍为 IN_PROGRESS。

**下一原任务：M1-01 的 macOS arm64 内部安装准备**。在已允许并行的桌面工程范围内复用已核验产物及本机，确定可重复的安装冒烟入口与包来源。三端实际安装、正式签名及 M1 整体验收仍按原门槛。M0-05 只有在新增可执行路径后才补对应真实 VM 验证；M1 数据/平台工程仍按原依赖排队。

## 每轮主线检查

开工、子任务完成及范围变化时，用 AGENTS 的五条规则核对：原任务、交付、退出条件、当前阻塞、最小验证、下一项。发现偏离立即收敛本轮范围；必要变更在这里和受影响原任务中记录，保留原生产验收要求。

进度格式：`原任务 ID / 实际交付 / 验收结果 / 父任务状态 / 下一项`。原始基础设施证据继续保存，报告优先说明它推进了哪项产品能力或原任务条件。
