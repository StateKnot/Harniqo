# 原生协议 Adapter 与显式能力准入

Harniqo 保留平台自己的资源、Run/Attempt、授权和事件契约，在执行代理中用不同 Adapter 连接各 Harness 原生协议。ACP 可作为一种底层协议，MCP/A2A/OTel 分别承担其工具、协作和观测职责，不能统一代替执行管理。

将所有 Harness 改造成同一个 Agent 循环可以简化界面，却会改变原生行为，削弱可复现比较；仅采用最小公共协议又容易丢审批、取消和恢复能力。因此核心流程统一，可选能力按版本和证据准入，保留原始事件和命名域，不支持时明确拒绝依赖该能力的工作流。

代价是维护多个真实 Adapter 和兼容矩阵，版本升级必须重跑契约验收。Octop 服务、Octop Harness 与外部委派组合分别登记，跨 Harness 切换创建新原生会话，不承诺隐藏上下文无损迁移。
